# Prompt Library

> Things I ask Claude often, in copy-pasteable form. Slash commands in `.claude/commands/` are the structured versions; this is for one-offs.

## Select Safety
- "Build a safety procedure from this note: [paste]. File it under `01-select-safety/safety-procedures/`."
- "Make this DOT checklist cleaner — tighten language, add reg citations, fix frontmatter: [paste]."
- "Create a training module for [topic], audience is [drivers / dispatch / management], duration ~[X] minutes."
- "Draft an incident report from these facts: [paste]. Use the Incident-Report template."
- "What safety docs need review? List anything in `01-select-safety/` past its review_frequency."

## Programs
- "Turn this into a program spec: [paste]."
- "What programs am I building? Status, stage, next action for each."
- "Audit this build plan and tell me what's missing or wrong."
- "Document this system: [paste or file pointer]."

## Day / week
- "Plan my day around my highest-value work."
- "What should I work on next?"
- "Generate this week's review."
- "Clean up my inbox."

## Research
- "Research [topic] and file the note under `05-research/`."
- "Summarize the differences between [reg A] and [reg B] and tell me what changes for my Select Safety SOPs."

## Vault hygiene
- "What's stale in this vault?"
- "Find orphan notes."
- "Which programs haven't been touched in 14 days?"
