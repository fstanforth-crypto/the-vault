---

Create a training module.

1. Ask for the topic and source material (procedure, SOP, or regulation it teaches).
2. Use `07-templates/Training-Module.md`.
3. File output under `01-select-safety/training/<kebab-case-name>.md`.
4. Build:
   - Learning objectives: 3-5, measurable ("can perform pre-trip inspection on a Class 8 tractor" not "understands pre-trip inspections").
   - Audience: who must take this.
   - Duration & delivery method.
   - Outline: section → topic → 1-2 sentence summary → time estimate.
   - Materials needed (handouts, video, equipment).
   - Assessment: quiz questions or hands-on demo criteria.
   - Records to keep: attendance, quiz scores, sign-off.
5. Link back to the source procedure/SOP/regulation with `[[wiki-links]]`.
6. Set `review_frequency` (default annual; OSHA-required topics may be more frequent).
