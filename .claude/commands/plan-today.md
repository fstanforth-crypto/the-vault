Build my plan for today and write it to `00-command-center/Today.md`.

Steps:
1. Read `00-command-center/Today.md` to see anything I've already pinned.
2. Scan for active items with high priority or near-due deadlines:
   - `01-select-safety/**` where `status` is `active`, `in-progress`, or `draft`
   - `02-programs-systems/active-programs/**` and `builds/**`
   - `03-projects/active/**`
3. Pick the 3-5 highest-value items for today, weighting in this order:
   - DOT/compliance items with deadlines this week
   - Active client commitments
   - Program build momentum (items in `build` or `test` stage)
4. Rewrite `Today.md` using the structure of `07-templates/Daily-Note.md`. Group items by area (Select Safety / Programs / Other).
5. After each item, add a one-line "why this is in today's plan."
6. Flag anything that's been on the plan 3+ days without movement.

Hard rules:
- Don't pick more than 5 priority items.
- Preserve anything I've manually added under "Notes" or "End-of-day."
- Don't touch any other file.
