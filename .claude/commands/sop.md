Draft an SOP.

1. Ask for the source — note path or pasted content.
2. Use `07-templates/SOP.md` as the structure.
3. File output under `01-select-safety/SOPs/<kebab-case-name>.md`, OR `02-programs-systems/documentation/` if it's an internal program SOP (ask which).
4. Frontmatter must include `department`, `owner`, `review_frequency`.
5. Writing rules:
   - Purpose, Scope, Owner, Effective date filled in.
   - Procedure steps: imperative, numbered, one action per step.
   - Responsibilities: role → action mapping.
   - Definitions: include any term a new hire wouldn't know.
   - References: link related procedures, regs, training.
6. Set up the Revision history table with an initial row.
7. Add `[[wiki-links]]` to related notes.

Output the file path; ask if anything needs revision before I treat it as the live SOP.
