Build a Select Safety procedure.

1. Ask which source notes to use (point me at a file in `06-inbox/` or paste content).
2. Use `07-templates/Safety-Procedure.md` as the structure.
3. File output under `01-select-safety/safety-procedures/<kebab-case-name>.md`.
4. Fill the frontmatter — especially `compliance_area`, `procedure_type`, `vehicle_type`, `driver_related`, `dot_related`, `review_frequency`.
5. Writing rules:
   - Professional, third-person, plain English.
   - Steps are imperative, numbered, one action per step.
   - Cite the regulation (FMCSR / OSHA / state) on any compliance-related step.
   - PPE, hazards, and emergency actions are non-optional sections — fill them or say "N/A — none applicable."
6. Add `[[wiki-links]]` to related procedures, training, and DOT notes you can find.
7. Link the new file back from `09-wiki/Safety-Knowledge.md`.

Output the path and ask if I want any wording changes before saving.
